Matriz de Roles y Privilegios

Esquema de autorización jerárquico verificado en tiempo de ejecución por RolesGuard.

ADMIN Nivel 3

Administrador

Control absoluto del sistema. Posee acceso exclusivo al CRUD completo de usuarios (/users), rutas privadas y públicas.

  • Gestión total de usuarios (Crear/Editar/Borrar)
  • Acceso a endpoints privados y perfil
USER Nivel 2 (Default)

Usuario Registrado

Asignado automáticamente al registrarse. Puede gestionar su propio perfil (requiriendo contraseña actual) y consultar rutas privadas.

  • Actualización segura de perfil
  • Acceso a zona privada (/private/users)
GUEST Nivel 1

Invitado / Anónimo

Sin permisos para endpoints protegidos. Solo puede interactuar con endpoints públicos (/public) o iniciar sesión/registrarse.

  • Acceso a endpoint libre /public
  • Bloqueado en rutas privadas (403 Forbidden)
